# W-072 — Contact through GitHub only; public decision records keep their W numbers

Date: 2026-11-17.

## Context

A public project needs a way to report security issues and conduct problems, and a numbering for
its decision records that matches the numbers already cited in its code and specifications.

## Decision

- **Contact goes through GitHub only.** Security reports use GitHub's private vulnerability
  reporting on the repository. Code of conduct reports use the same channel or a private message to
  a maintainer on GitHub. No e-mail address is published.
- **Decision records keep their W numbers.** The public repository holds short English records of
  the decisions that matter to users and contributors, under their original numbers, with gaps
  where a record is kept private. Code and specifications keep citing W numbers.

## Consequences

- See `SECURITY.md` and `CODE_OF_CONDUCT.md` in the repository, and the [index](README.md).
